# Relatórios

A página autenticada reúne inscrições, progresso, tentativas de avaliação, certificados e trilhas da API do colaborador. Os indicadores mostram apenas dados da conta atual. Mesmo sem conclusões, a tela mostra cursos inscritos, seu progresso e avaliações realizadas. O filtro permite consultar todo o histórico ou os eventos do ano corrente. O CSV exporta os totais e a atividade mensal do ano corrente.

Horas representam a carga horária dos certificados emitidos, não tempo de navegação medido. O progresso de trilhas é a média dos cursos que as compõem. Não há ranking fictício nem números de outros colaboradores nessa visão pessoal.
